# Mini threat model — index7

## Scope

Публичный учебный кейс `Система обучения — Деловые Линии`, его статические файлы, браузерная сессия, локальное состояние и только те локальные лабораторные сервисы, которые лежат в этом репозитории.

## Assets

1. Целостность учебного контента и логики тренажёра.
2. Данные, вводимые посетителем в демонстрационные формы.
3. Состояние прохождения/результата, если оно сохраняется локально.
4. Конфигурация и секреты локальных лабораторных сервисов.
5. Целостность содержимого репозитория и публикации GitHub Pages.

## Trust boundaries

`visitor → browser DOM → local state → optional local lab`

`developer workstation → Git → repository → GitHub Pages`

## Risks and controls — Abuse cases / rate limit / идемпотентность / устойчивость

| ID | Risk | Scenario | Control |
|---|---|---|---|
| T1 | Burst abuse | Один клиент генерирует много событий | Sliding-window rate limit |
| T2 | Повтор операции | Клиент ретраит POST и создаёт дубль | Idempotency key |
| T3 | Предсказуемый идентификатор | Можно перебирать чужие объекты | Непредсказуемый id + авторизация |
| T4 | Нет деградации | Ошибка зависимости превращается в ложный success | Явный failure/retry state |
| T5 | Потеря событий | Сбой между приёмом и записью | Идемпотентная обработка и локальный журнал теста |

## Residual risk

Статический публичный кейс не превращается в промышленное приложение только из-за наличия security-документации. Там, где отсутствует сервер, серверные меры показаны только в локальных учебных лабораториях и не выдаются за часть реальной инфраструктуры компании.
